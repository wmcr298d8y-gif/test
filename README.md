# 現場工数記録

建設現場などで、**工種別の工数（延べ時間・人工）** を記録・集計するための Web アプリです。
ビルド不要・外部ライブラリなしの HTML / CSS / JavaScript だけで動き、スマートフォンでの現場入力を想定しています。

## 主な機能

| タブ | できること |
| --- | --- |
| 入力 | 日付・現場・工種・作業者（業者）・人数・時間・数量（出来高）を記録。時間は「時間で入力」か「開始・終了・休憩」から自動計算。延べ工数と人工をその場で表示。その日の記録の編集・複製・削除 |
| 一覧 | 期間・現場・工種で絞り込み、件数と合計を表示。表示中の記録を CSV 出力 |
| 集計 | 今週／今月／先月／全期間などで、**工種別の実績歩掛り**（現場ごとにも表示可）、工種別・現場別の延べ工数・人工・比率、工種 × 日付のクロス集計 |
| 設定 | 現場・工種・作業者のマスタ管理（追加・名前変更・並べ替え・削除）、工種ごとの数量の単位と標準歩掛り、1人工の時間（既定 8h）、JSON バックアップ／復元、CSV 出力／取り込み |

- 延べ工数(h) = 人数 × 1人あたり時間
- 人工 = 延べ工数 ÷ 1人工の時間（設定で変更可）
- CSV は BOM 付き UTF-8 なので Excel でそのまま開けます。アプリが出力した CSV は取り込みにも使えます（未登録の現場・工種は自動追加）。

## 歩掛りの算出

歩掛りは「1単位（m³・m²・t など）を施工するのに必要な人工」です。

- **歩掛り（人工/単位）** = 期間内の人工合計 ÷ 期間内の数量合計
- **1人工あたり施工量** = 数量合計 ÷ 人工合計（歩掛りの逆数）
- **対標準** = 実績歩掛り ÷ 標準歩掛り × 100%（100% を超えると標準より手間がかかっている）

数量は毎日入れる必要はありません。たとえば型枠を 3 日かけて 80m² 組んだ場合、最終日にまとめて 80 と入れても、
3 日分の人工が分子に入るため正しい歩掛りになります。一方、数量を入れる前に集計期間を区切ると、
その期間は手間だけが計上されて歩掛りが大きく出るので、区切りのよい期間で比較してください。

工種の単位は「設定」で変更できます（初期値: 土工事・基礎・コンクリート m³、型枠・仮設・内装 m²、鉄筋・鉄骨 t、設備・雑 式）。

## 使い方

`index.html` をブラウザで開くだけで使えます。

ホーム画面に追加してオフラインでも使いたい場合は、HTTP(S) で配信してください（Service Worker が有効になります）。

```sh
npm start          # http://localhost:8080 で起動
```

GitHub Pages などの静的ホスティングにそのまま置くこともできます。

1. 「設定」タブで現場を登録（工種は代表的なものが単位付きで初期登録済み。必要なら標準歩掛りも入力）
2. 「入力」タブで記録
3. 施工量が分かったら数量も入力
4. 「集計」タブで工種別の工数・歩掛りを確認、必要なら CSV 出力

## データの保存について

データは端末のブラウザ（localStorage）に保存され、サーバーには送信されません。
そのため端末・ブラウザごとにデータは別になります。機種変更やブラウザのデータ削除に備え、
「設定 → バックアップ(JSON)を保存」で定期的にバックアップしてください。

```
js/app.js           画面の制御
sw.js               オフライン用 Service Worker
test/core.test.js   単体テスト
```

```sh
npm test            # Node.js 18 以上
```
