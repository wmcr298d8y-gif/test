# 現場日報

電気設備工事の現場で、**日報**を毎日残し、慣れてきたら **工種別の工数** も記録して自社の実績歩掛を貯めるための Web アプリです。

- **日報（必須）**: 1 分で終わる量に絞った毎日の記録。担当者が休んで代わりの人が現場に行っても、
  過去の日報と現場ノートを見れば「今日は何をどこまでやるか」が分かることを目的にしています。
- **工数（任意）**: 日報の出面を工種ごとに割り振る詳細な記録。徐々に使ってもらう想定です。

## 主な機能

画面は **現場用**（各現場の代表者）と **管理者用** に分かれています。
本番では kintone にログインしたアカウントで切り替わる想定で、モックでは画面右上のボタンで切り替えます。

| タブ | 現場用 | 管理者用 | できること |
| --- | :-: | :-: | --- |
| 日報 | ◯ | ◯ | **必須**。天候、出面（自社・協力会社ごとの人工。半日は 0.5）、今日の作業（場所＋作業＋完了／途中＋備考＋作業ごとの写真）、明日の予定、特記事項、その他の写真、ふりかえり（本人と管理者のみ）。前日の「明日の予定」と途中の作業から下書きが作られ（状態は未選択）、完了か途中を選ぶ。今日で終わらなかった作業（手を付けられなかった作業も）は「途中」として今日の記録に残し、備考に進み具合・できなかった理由を書く。途中の作業は明日の予定へ「繰越」として自動で入り、翌日の下書きには前回の備考と写真を参考表示。管理者は日報に返信でき、現場用には未読の返信をお知らせ（本番は kintone のコメント機能を想定） |
| 工数 | ◯ | ◯ | **任意**。工種（大分類 → 小分類）・人数・時間・数量・難度を行ごとに入力。日報の出面に対して割り振り済みの人工と残りを表示し、日報の作業（場所＋作業を備考に入れた行）を取り込める |
| 現場 | ◯ | ◯ | **引き継ぎ用**。現場ノート（元請の連絡先・朝礼・ルール・鍵や資材の場所・注意点）、今日やること、近日の予定（検査・搬入など）、これまでの日報 |
| 累計 | ◯ | ◯ | 現場ごとに、任意の時点または完工時までの工種別の累計工数・数量・実績歩掛 |
| 集計 | − | ◯ | 日報の提出状況（直近 7 日・未提出から日報を開ける）、月別・工種別、実績歩掛、大分類別・小分類別・現場別の工数、工数の明細と CSV 出力 |
| 歩掛 | − | ◯ | 自社の実績歩掛（完工現場・工事区分・難度で絞り込み、積算の歩掛マスタ用に CSV 出力） |
| 設定 | − | ◯ | 現場（工事区分・状態・完工日）、工事区分、社員、工種、1人工の時間、バックアップ／復元 |

日報・工数・現場の 3 つのタブでは、画面上部の「入力者・日付・現場」が共通です。

- 延べ工数(h) = 人数 × 1人あたり時間
- 人工 = 延べ工数 ÷ 1人工の時間（設定で変更可）
- CSV は BOM 付き UTF-8 なので Excel でそのまま開けます。アプリが出力した CSV は取り込みにも使えます（現場は作番で照合）。

## 歩掛の算出

歩掛は「1単位（m・個・台など）を施工するのに必要な人工」です。このアプリは **自社の実績歩掛** を貯めて出すのが目的で、
自社の歩掛マスタそのものは積算側で持ちます。

```
現場の日報（工数・数量・難度）→ 工種別の実績歩掛（完工現場）→ CSV → 積算の自社歩掛マスタ
```

- **歩掛（人工/単位）** = 人工合計 ÷ 数量合計（規模の大きい現場ほど重みが大きい加重平均）
- **1人工あたり施工量** = 数量合計 ÷ 人工合計（歩掛の逆数）
- 数量は毎日入れる必要はありません。同じ現場の中で数量を入れていない日の工数も分子に含むので、施工が終わった日にまとめて入れても正しい値になります。
- 「歩掛」タブでは、その工種の数量を **一度も入れていない現場** は手間だけが計上されて値が過大になるため計算から除き、「数量なし」に件数を出します。
- 現場数が 2 以下の工種は「参考」と表示します。現場ごとの最小〜最大でばらつきも確認してください。
- 工事区分（新築・改修など）と難度（標準のみ／難のみ）で絞り込めるので、条件別の歩掛も出せます。

## 初期登録の工種（電気設備工事）

| 大分類 | 小分類（単位） |
| --- | --- |
| 準備・仮設 | 墨出し(式)、資材搬入・小運搬(式)、仮設電気(式)、片付け・清掃(式) |
| 配管工事 | 電線管敷設（露出／隠ぺい／打込み・埋設）(m)、ボックス取付(個)、ケーブルラック敷設(m)、金属ダクト・レースウェイ(m) |
| 配線工事 | 幹線ケーブル敷設(m)、電線入線(m)、ケーブル配線（VVF等）(m)、端末処理・結線(箇所) |
| 盤・受変電設備 | 分電盤据付(面)、動力盤・制御盤据付(面)、キュービクル据付(基)、盤内結線(面) |
| 照明・配線器具 | 照明器具取付(台)、非常照明・誘導灯取付(台)、スイッチ取付(個)、コンセント取付(個) |
| 弱電・通信設備 | LAN配線(m)、情報コンセント取付(個)、電話・TV配線(m)、放送・インターホン機器取付(台)、防犯カメラ設置(台) |
| 防災設備 | 自火報 感知器取付(個)、受信機・発信機取付(台)、防災配線(m) |
| 接地・避雷 | 接地工事(箇所)、避雷設備(式) |
| 外線・引込 | 引込工事(式)、ハンドホール設置(箇所)、地中管路敷設(m) |
| 試験・調整 | 絶縁抵抗・接地抵抗測定(回路)、動作試験・調整(式)、検査立会い(式) |
| 改修・撤去 | 既存設備撤去(式)、既存配線撤去(m) |
| その他 | はつり・貫通・補修(箇所)、その他作業(式) |

自社の分け方に合わせて「設定」で自由に追加・名前変更・削除できます。削除してしまった標準工種は
「電気設備の標準工種を追加（不足分のみ）」で戻せます。以前のバージョンで作ったデータの工種は、大分類「未分類」にまとめて引き継がれます。

## 使い方

`index.html` をブラウザで開くだけで使えます。

ホーム画面に追加してオフラインでも使いたい場合は、HTTP(S) で配信してください（Service Worker が有効になります）。

```sh
npm start          # http://localhost:8080 で起動
```

GitHub Pages などの静的ホスティングにそのまま置くこともできます。

1. （管理者）「設定」で現場・社員を確認（本番は kintone から取得）。工種は電気設備工事の大分類・小分類が単位付きで初期登録済み
2. （管理者）「設定」で現場ごとに工事区分を設定
3. （現場）「現場」で現場ノートを書いておく（代わりの人が最初に読む情報）
4. （現場）毎日「日報」を保存。前日の予定から下書きされるので、完了・途中を選んで直すだけ
5. （現場・慣れてきたら）「工数」で日報の出面を工種ごとに割り振る。「累計」で自分の現場の実績歩掛を確認
6. （管理者）「集計」で日報の提出状況と月別・工種別の工数を確認。完工したら「設定」で完工にする
7. （管理者）「歩掛」で自社の実績歩掛を確認し、CSV で積算の歩掛マスタへ

## お試し（プレビュー公開）

初回起動時の「サンプルデータで試す」で、サンプルの現場 4 件（うち完工 2 件）・社員 3 名・日報・現場ノート・予定・工数が入ります。サンプルは「管理者用 → 設定 → 全データを削除」で消せます。

claude.ai のページとして公開する 1 ファイル版は次で作れます（`dist/` に出力、Git 管理外）。

```sh
npm run build:artifact
```

写真は端末のブラウザに保存するため、モックでは 1 日 4 枚まで・長辺 1280px に縮小しています（本番は kintone の添付ファイルを想定）。
公開ページではファイルの保存ができないため、CSV・バックアップは出力画面の「コピー」から Excel などに貼り付けてください。

## データの保存について

データは端末のブラウザ（localStorage）に保存され、サーバーには送信されません。
そのため端末・ブラウザごとにデータは別になります。機種変更やブラウザのデータ削除に備え、
「設定 → バックアップ(JSON)を保存」で定期的にバックアップしてください。
