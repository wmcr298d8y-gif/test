# 現場工数記録

電気設備工事の現場で、**工種別の工数（延べ時間・人工）と歩掛り** を記録・集計するための Web アプリです。
工種は **大分類 → 小分類** の 2 段階で選びます。
ビルド不要・外部ライブラリなしの HTML / CSS / JavaScript だけで動き、スマートフォンでの現場入力を想定しています。

## 主な機能

画面は **現場用**（各現場の代表者）と **管理者用** に分かれています。
本番では kintone にログインしたアカウントで切り替わる想定で、モックでは画面右上のボタンで切り替えます。

| タブ | 現場用 | 管理者用 | できること |
| --- | :-: | :-: | --- |
| 入力 | ◯ | ◯ | **日報形式**。入力者（社員）・日付・現場を選び、その日の作業（工種＝大分類 → 小分類、人数、時間、数量、難度、備考）を何行でも並べて「保存」で一括登録。高所・狭所など手間のかかる作業は行ごとに「難」をチェック。人数は 1 人、時間は 0.25h 刻みの ▲▼ ボタンで増減（長押しで連続）。「前回の作業を呼び出す」で同じ現場の直近の日の作業を複写。完工済みの現場は入力不可（現場用では選択肢にも出ない） |
| 一覧 | ◯ | ◯ | 期間・現場・大分類・小分類で絞り込み、件数と合計を表示。CSV 出力 |
| 累計 | ◯ | ◯ | 現場ごとに、**任意の時点**（今日・先月末・日付指定）または **完工時** までの累計工数・数量・実績歩掛りを工種別に表示 |
| 集計 | − | ◯ | 期間で絞り込み、**月別・工種別**（人工／時間の切替、大分類ごとに小計）、小分類ごとの実績歩掛り、大分類別・小分類別・現場別の工数 |
| 歩掛り | − | ◯ | **自社の実績歩掛り**。完工現場の記録から工種ごとの歩掛り・現場数・現場ごとの最小〜最大・難の割合を出し、工事区分・難度・期間で絞り込み。積算の歩掛りマスタ用に CSV 出力 |
| 設定 | − | ◯ | 現場（工事区分、状態＝稼働中／完工、完工日）、工事区分、社員、工種、1人工の時間、バックアップ／復元 |

- 延べ工数(h) = 人数 × 1人あたり時間
- 人工 = 延べ工数 ÷ 1人工の時間（設定で変更可）
- CSV は BOM 付き UTF-8 なので Excel でそのまま開けます。アプリが出力した CSV は取り込みにも使えます（現場は作番で照合）。

## kintone との関係（予定）

| データ | 持ち場所 | このアプリでの扱い |
| --- | --- | --- |
| 現場（作番・現場名） | kintone の現場アプリ | 読み取り。モックでは「設定」で模擬追加 |
| 社員（管理番号・氏名） | kintone の社員アプリ | 読み取り。日報の入力者として選択 |
| 現場の工事区分・状態・完工日 | このアプリ | 管理者が設定 |
| 工種・工事区分 | このアプリ | 管理者が登録 |
| 日報 | このアプリ（保存先は kintone を想定） | 現場代表者が入力 |

## 歩掛りの算出

歩掛りは「1単位（m・個・台など）を施工するのに必要な人工」です。このアプリは **自社の実績歩掛り** を貯めて出すのが目的で、
自社の歩掛りマスタそのものは積算側で持ちます。

```
現場の日報（工数・数量・難度）→ 工種別の実績歩掛り（完工現場）→ CSV → 積算の自社歩掛りマスタ
```

- **歩掛り（人工/単位）** = 人工合計 ÷ 数量合計（規模の大きい現場ほど重みが大きい加重平均）
- **1人工あたり施工量** = 数量合計 ÷ 人工合計（歩掛りの逆数）
- 数量は毎日入れる必要はありません。同じ現場の中で数量を入れていない日の工数も分子に含むので、施工が終わった日にまとめて入れても正しい値になります。
- 「歩掛り」タブでは、その工種の数量を **一度も入れていない現場** は手間だけが計上されて値が過大になるため計算から除き、「数量なし」に件数を出します。
- 現場数が 2 以下の工種は「参考」と表示します。現場ごとの最小〜最大でばらつきも確認してください。
- 工事区分（新築・改修など）と難度（標準のみ／難のみ）で絞り込めるので、条件別の歩掛りも出せます。

## 初期登録の工種（電気設備工事）

| 大分類 | 小分類（単位） |
| --- | --- |
| 準備・仮設 | 墨出し(式)、資材搬入・小運搬(式)、仮設電気(式)、片付け・清掃(式) |
| 配管工事 | 電線管敷設（露出／隠ぺい／打込み・埋設）(m)、ボックス取付(個)、ケーブルラック敷設(m)、金属ダクト・レースウェイ(m) |
| 配線工事 | 幹線ケーブル敷設(m)、電線入線(m)、ケーブル配線（VVF等）(m)、端末処理・結線(箇所) |
| 盤・受変電設備 | 分電盤据付(面)、動力盤・制御盤据付(面)、キュービクル据付(基)、盤内結線(面) |
| 照明・配線器具 | 照明器具取付(台)、非常照明・誘導灯取付(台)、スイッチ取付(個)、コンセント取付(個) |
| 弱電・通信設備 | LAN配線(m)、情報コンセント取付(個)、電話・TV配線(m)、放送・インターホン機器取付(台)、防犯カメラ設置(台) |
| 防災設備 | 自火報 感知器取付(個)、受信機・発信機取付(台)、防災配線(m) |
| 接地・避雷 | 接地工事(箇所)、避雷設備(式) |
| 外線・引込 | 引込工事(式)、ハンドホール設置(箇所)、地中管路敷設(m) |
| 試験・調整 | 絶縁抵抗・接地抵抗測定(回路)、動作試験・調整(式)、検査立会い(式) |
| 改修・撤去 | 既存設備撤去(式)、既存配線撤去(m) |
| その他 | はつり・貫通・補修(箇所)、その他作業(式) |

自社の分け方に合わせて「設定」で自由に追加・名前変更・削除できます。削除してしまった標準工種は
「電気設備の標準工種を追加（不足分のみ）」で戻せます。以前のバージョンで作ったデータの工種は、大分類「未分類」にまとめて引き継がれます。

## 使い方

`index.html` をブラウザで開くだけで使えます。

ホーム画面に追加してオフラインでも使いたい場合は、HTTP(S) で配信してください（Service Worker が有効になります）。

```sh
npm start          # http://localhost:8080 で起動
```

GitHub Pages などの静的ホスティングにそのまま置くこともできます。

1. （管理者）「設定」で現場・社員を確認（本番は kintone から取得）。工種は電気設備工事の大分類・小分類が単位付きで初期登録済み
2. （管理者）「設定」で現場ごとに工事区分を設定
3. （現場）「入力」で入力者・日付・現場を選び、その日の作業を行ごとに入力して「保存」（翌日以降は「前回の作業を呼び出す」が便利）
4. （現場）「累計」で自分の現場の累計と実績歩掛りを確認
5. （管理者）「集計」で月別・工種別の工数を確認。完工したら「設定」で完工にする
6. （管理者）「歩掛り」で自社の実績歩掛りを確認し、CSV で積算の歩掛りマスタへ

## お試し（プレビュー公開）

初回起動時の「サンプルデータで試す」で、サンプルの現場 4 件（うち完工 2 件）・社員 3 名・記録が入ります。サンプルは「管理者用 → 設定 → 全データを削除」で消せます。

claude.ai のページとして公開する 1 ファイル版は次で作れます（`dist/` に出力、Git 管理外）。

```sh
npm run build:artifact
```

公開ページではファイルの保存ができないため、CSV・バックアップは出力画面の「コピー」から Excel などに貼り付けてください。

## データの保存について

データは端末のブラウザ（localStorage）に保存され、サーバーには送信されません。
そのため端末・ブラウザごとにデータは別になります。機種変更やブラウザのデータ削除に備え、
「設定 → バックアップ(JSON)を保存」で定期的にバックアップしてください。
