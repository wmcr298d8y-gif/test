# 現場工数記録

電気設備工事の現場で、**工種別の工数（延べ時間・人工）と歩掛り** を記録・集計するための Web アプリです。
工種は **大分類 → 小分類** の 2 段階で選びます。
ビルド不要・外部ライブラリなしの HTML / CSS / JavaScript だけで動き、スマートフォンでの現場入力を想定しています。

## 主な機能

| タブ | できること |
| --- | --- |
| 入力 | **日報形式**。日付と現場を選び、その日の作業（工種＝大分類 → 小分類、人数、時間、数量、作業者、備考）を何行でも並べて「保存」で一括登録。人数は 1 人、時間は 0.25h 刻みの ▲▼ ボタンで増減（長押しで連続）。行の追加時は大分類・人数・時間・作業者を前の行から引き継ぎ、「前回の作業を呼び出す」で同じ現場の直近の日の作業を複写（数量は空欄）。保存済みの日を開けばそのまま修正・削除。同じ日の他の現場へワンタップで切替 |
| 一覧 | 期間・現場・大分類・小分類で絞り込み、件数と合計を表示。表示中の記録を CSV 出力 |
| 集計 | 今週／今月／先月／全期間などで、**小分類ごとの実績歩掛り**（現場ごとにも表示可）と歩掛りマスタとの比較、大分類別・小分類別・現場別の延べ工数・人工・比率、大分類 × 日付のクロス集計 |
| 歩掛り | 歩掛りマスタ（国交省・元請別など）を複数登録。小分類ごとに歩掛りを入力、複製、CSV 出力（Excel 入力用ひな形）／取り込み |
| 設定 | 現場（元請の歩掛りマスタを紐づけ）・大分類・小分類・作業者のマスタ管理（追加・名前変更・並べ替え・削除・大分類の移動）、小分類ごとの数量の単位、1人工の時間（既定 8h）、JSON バックアップ／復元、CSV 出力／取り込み |

- 延べ工数(h) = 人数 × 1人あたり時間
- 人工 = 延べ工数 ÷ 1人工の時間（設定で変更可）
- CSV は BOM 付き UTF-8 なので Excel でそのまま開けます。アプリが出力した CSV は取り込みにも使えます（未登録の現場・工種は自動追加）。

## 歩掛りの算出

歩掛りは「1単位（m³・m²・t など）を施工するのに必要な人工」です。

- **歩掛り（人工/単位）** = 期間内の人工合計 ÷ 期間内の数量合計
- **1人工あたり施工量** = 数量合計 ÷ 人工合計（歩掛りの逆数）
- **対比** = 実績歩掛り ÷ マスタの歩掛り × 100%（100% を超えると赤。マスタより手間がかかっている）

数量は毎日入れる必要はありません。たとえば型枠を 3 日かけて 80m² 組んだ場合、最終日にまとめて 80 と入れても、
3 日分の人工が分子に入るため正しい歩掛りになります。一方、数量を入れる前に集計期間を区切ると、
その期間は手間だけが計上されて歩掛りが大きく出るので、区切りのよい期間で比較してください。

歩掛りは小分類ごとに算出します（単位が小分類ごとに違うため）。大分類単位では工数の合計のみを集計します。

## 歩掛りマスタ

「国交省 R7年度」「○○建設」のように、比較の基準にする歩掛りを何種類でも登録できます（「歩掛り」タブ）。

- 小分類ごとに 1単位あたりの人工（人工/単位）を入力します。未入力の小分類は比較で「—」になります。
- **CSV で一括登録**: 「CSV 出力」で全小分類を並べたひな形（`大分類,小分類,単位,歩掛り(人工/単位)`）が出るので、
  Excel で歩掛り列を埋めて「CSV を取り込む」。空欄の行は読み飛ばし、既存の値は消しません。
  CSV に未登録の小分類（例: 「電線管敷設（露出）PF16」のように管種・サイズ別に分けたもの）があれば自動で追加します。
- 「複製」で既存マスタをコピーして、年度更新や元請ごとの微修正に使えます。
- 「設定」の現場に元請のマスタを紐づけると、集計の比較で「各現場の元請マスタ」を選べます（現場ごと表示で有効）。
- 集計画面の「比較」で表示するマスタを複数選べます（選択は保存されます）。

> 国交省（公共建築工事標準単価積算基準など）の歩掛り値はアプリに同梱していません。
> 公表資料から、上記の CSV ひな形に転記して取り込んでください。

## 初期登録の工種（電気設備工事）

| 大分類 | 小分類（単位） |
| --- | --- |
| 準備・仮設 | 墨出し(式)、資材搬入・小運搬(式)、仮設電気(式)、片付け・清掃(式) |
| 配管工事 | 電線管敷設（露出／隠ぺい／打込み・埋設）(m)、ボックス取付(個)、ケーブルラック敷設(m)、金属ダクト・レースウェイ(m) |
| 配線工事 | 幹線ケーブル敷設(m)、電線入線(m)、ケーブル配線（VVF等）(m)、端末処理・結線(箇所) |
| 盤・受変電設備 | 分電盤据付(面)、動力盤・制御盤据付(面)、キュービクル据付(基)、盤内結線(面) |
| 照明・配線器具 | 照明器具取付(台)、非常照明・誘導灯取付(台)、スイッチ取付(個)、コンセント取付(個) |
| 弱電・通信設備 | LAN配線(m)、情報コンセント取付(個)、電話・TV配線(m)、放送・インターホン機器取付(台)、防犯カメラ設置(台) |
| 防災設備 | 自火報 感知器取付(個)、受信機・発信機取付(台)、防災配線(m) |
| 接地・避雷 | 接地工事(箇所)、避雷設備(式) |
| 外線・引込 | 引込工事(式)、ハンドホール設置(箇所)、地中管路敷設(m) |
| 試験・調整 | 絶縁抵抗・接地抵抗測定(回路)、動作試験・調整(式)、検査立会い(式) |
| 改修・撤去 | 既存設備撤去(式)、既存配線撤去(m) |
| その他 | はつり・貫通・補修(箇所)、その他作業(式) |

自社の分け方に合わせて「設定」で自由に追加・名前変更・削除できます。削除してしまった標準工種は
「電気設備の標準工種を追加（不足分のみ）」で戻せます。以前のバージョンで作ったデータの工種は、大分類「未分類」にまとめて引き継がれます。

## 使い方

`index.html` をブラウザで開くだけで使えます。

ホーム画面に追加してオフラインでも使いたい場合は、HTTP(S) で配信してください（Service Worker が有効になります）。

```sh
npm start          # http://localhost:8080 で起動
```

GitHub Pages などの静的ホスティングにそのまま置くこともできます。

1. 「設定」タブで現場を登録（工種は電気設備工事の大分類・小分類が単位付きで初期登録済み。必要なら自社の分類に修正）
2. 「歩掛り」タブで国交省・元請の歩掛りマスタを登録し、「設定」で現場に元請マスタを紐づけ
3. 「入力」タブで日付と現場を選び、その日の作業を行ごとに入力して「保存」（翌日以降は「前回の作業を呼び出す」が便利）
4. 施工量が分かったら数量も入力（あとからその日を開いて追記できます）
5. 「集計」タブで工種別の工数・実績歩掛りをマスタと比較、必要なら CSV 出力

## お試し（プレビュー公開）

初回起動時の「サンプルデータで試す」で、サンプルの現場・歩掛りマスタ・2 週間分の記録が入ります
（歩掛りの値はお試し用の仮の値です）。サンプルは「設定 → 全データを削除」で消せます。

claude.ai のページとして公開する 1 ファイル版は次で作れます（`dist/` に出力、Git 管理外）。

```sh
npm run build:artifact
```

公開ページではファイルの保存ができないため、CSV・バックアップは出力画面の「コピー」から Excel などに貼り付けてください。

## データの保存について

データは端末のブラウザ（localStorage）に保存され、サーバーには送信されません。
そのため端末・ブラウザごとにデータは別になります。機種変更やブラウザのデータ削除に備え、
「設定 → バックアップ(JSON)を保存」で定期的にバックアップしてください。
